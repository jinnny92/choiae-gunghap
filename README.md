# 최애 궁합 — 배포 안내

서버·DB 없는 정적 웹사이트입니다. 셀럽 목록은 GitHub이 매주 Wikidata에서 자동으로 받아와 갱신합니다.

## 처음 한 번만 하면 되는 설정 (약 15분)

1. **GitHub 저장소 만들기**: github.com → New repository → 이 폴더의 파일을 전부 올리기
   (`.github` 폴더가 숨김 폴더라 빠지기 쉬워요. 꼭 같이 올리세요)
2. **셀럽 목록 처음 받기**: 저장소 → Actions 탭 → "셀럽 목록 자동 업데이트" → Run workflow
   → 1~2분 뒤 `celebs.js`가 수천 명 목록으로 바뀐 커밋이 생기면 성공
3. **사이트 연결**: Cloudflare Pages(또는 Vercel) → 새 프로젝트 → 이 GitHub 저장소 선택
   → 빌드 명령 비워두기, 출력 폴더 `/` → 배포

이후엔 매주 월요일 새벽 목록이 자동 갱신되고, 사이트도 자동으로 다시 배포됩니다.

## 파일
- `index.html`, `app.js` — 화면
- `logic.js` — 일간(일주 천간)·별자리·점수 계산
- `data.js` — 카드 100장, 타로 22장, 풀이 문구
- `celebs.js` — 셀럽 목록 (자동 생성, 직접 수정하지 말 것)
- `tools/fetch_celebs.mjs` — Wikidata 수집 스크립트
- `tools/celebs-overrides.json` — 자동 수집 결과 보정
  - `exclude`: 빼달라는 요청이 오거나 잘못된 사람의 Wikidata ID (예: `"Q12345"`)
  - `fix`: 그룹명 등 특정 값 수정 (예: `{"Q12345": {"group": "새 그룹명"}}`)
  - `add`: 목록에 없는 사람 직접 추가
- `tools/CARD_SPEC.md`, `tools/cards.csv` — 카드 체계 문서

## 수집 기준
- 한국 국적, 직업이 가수·래퍼·댄서·배우, 생일이 일 단위까지 기록된 사람
- 위키 문서가 4개 언어 이상 있는 사람 (너무 무명인 경우 제외), 인지도순 최대 4,000명
- 고인, 출처마다 생일이 다른 사람은 제외
- 받아온 인원이 200명 미만이면 오류로 보고 기존 목록 유지
